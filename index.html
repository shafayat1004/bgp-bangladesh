    How Does Bangladesh's Internet Connect to the World?

    What You're Looking At

    This visualization shows the BGP (Border Gateway Protocol) routes that connect Bangladesh to the global internet. Every time you visit a website or send a message, your data travels along paths like these.

    Note: The site shows the busiest 1,500 international connections and 2,000 local connections, which cover nearly all the routes seen while keeping the charts readable.

    How to Use

    • Switch tabs to see different visualizations of the same data (arrow keys move between tabs)
    • Hover over a network for details about it
    • Click a network in a chart or in the sidebar to highlight its connections
    • Pan and zoom with the chart buttons, or focus a chart and use the arrow keys, + and -
    • Use filters in the sidebar to adjust what's shown
    • Data Table lists every network and connection as text
    • Press ? next to a term for a plain explanation and an example
    • Fetch Latest Routes rebuilds the data from RIPEstat in your browser (it takes 15-20 minutes)
    • Export the data as CSV to analyze in a spreadsheet

    Why This Matters

    Understanding these paths reveals bottlenecks and single points of failure. If a major gateway goes down, whether intentionally or due to a submarine cable cut, it affects millions of users. This tool helps visualize that dependency.

    How Classification Works

    Every ASN is classified through a multi-step pipeline: external BGP data is fetched from RIPEstat and PeeringDB, AS paths are analysed to identify border crossings, and gateways are categorised using BTRC license data, IP geolocation, and transit analysis. For the full algorithm, see the Classification Pipeline Documentation (opens in a new tab).
